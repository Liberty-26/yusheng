# ASH DISTRICT / 末日街区地图原型

独立 Godot 4.x 3D 工程。180 × 180 m；固定正交斜俯视镜头，水平 45°、俯角约 43°。只验证地图、基础美术、镜头、建筑剖切。没有人物或游戏系统，没有连接 Python。

## 直接运行

双击同目录 `启动地图.command`，或在 Godot 导入 `project.godot` 后按 F6/F5（主场景运行用 F5）。Main Scene：`scenes/map/main.tscn`。

## 操作

| 操作 | 按键 |
|---|---|
| 平移 | WASD / 按住鼠标右键或中键拖动 |
| 缩放 | 鼠标滚轮 |
| 总览 | F1 |
| 聚焦便利店 | F2 |
| 聚焦两层住宅 | F3 |
| 便利店外观 / 室内 | C 或左键点击便利店 |
| 住宅外观 / 1F / 2F 循环 | H 或左键点击住宅 |
| 住宅 Exterior / 1F / 2F | 数字 1 / 2 / 3 |

部分 Mac 键盘需按住 fn 使用 F1–F3。上述操作仅针对纯地图观察场景：该场景没有自由旋转，也没有屏幕 UI。试玩场景已支持 360° 水平旋转，具体操作见后文“试玩相机与地图重构基础”。按 F1 只复位镜头，不改变楼层；C、数字 1 可恢复外观。

## 内容

便利店、诊所、加油站、两层住宅、封窗废弃住宅、仓库、停车场、未来营地空地、一条主街与两条纵向巷道。含少量车辆、路障、路灯、围栏、垃圾箱、箱子、水罐、断墙和植被。灰蓝、灰绿、水泥灰和褪色红为主，局部暖光。简单高粗糙度材质，无外部资产依赖。

便利店：前门、营业区、收银台、储藏区、后门。C 隐藏屋顶和近镜头两侧墙。
住宅：客厅、厨房、楼梯、卧室、走廊及二楼楼梯洞口。1F 模式隐藏屋顶和整个 2F；2F 模式隐藏屋顶与 1F。

## 工程与未来资产替换

`district.gd` 使用固定随机种子组装独立 MeshInstance3D，没有合并为大 Mesh。建筑独立快照保存在 `scenes/buildings/`，可在编辑器直接打开检查；运行地图目前由生成脚本组装，修改快照不会自动影响运行地图。

建筑根节点有 building_id；Floor1 / Floor2 有 floor_id；Rooms 子节点有 room_id；InteractionPoints 留出入口语义。Roof、FarWalls、NearWalls、Rooms 单独组织。未来以 Blender 米制、应用变换的低模模块导出 GLB，替换几何体子节点，保留这些语义父节点与局部坐标。建议模块 Wall_2m / Wall_4m / Door / Window / Floor / Roof / Stair / Fence。

目前碰撞体仅用于建筑点击选择，不是行走碰撞；没有 Navigation 烘焙，也没有交互动作。房间和入口是未来接入的位置约定。本版几何体比例仍是供视觉判断的占位资产，不是施工尺度规范。

`materials/` 与 `assets/` 为后续正式资源预留；当前材质由脚本生成并随建筑场景嵌入保存。当前采用 Compatibility 渲染器，方便本机直接运行。

## 验证与截图

在本机 Godot 4.7.2 / Apple A18 Pro 图形模式运行。`-- --capture` 启动参数执行输入与可见性断言，保存六张真实视口截图到 screenshots，完成后返回总览并保持窗口打开。

六张图分别为街区、便利店外观、便利店室内、住宅外观、住宅一楼、住宅二楼。验证日志见 `verification.log`。

本版到地图原型为止；美术方向是否符合预期由用户看图和实际观察决定，不把程序运行成功当成美术认可。

## 2026-09-08 试玩小范围优化

本节仅适用于 `启动试玩.command` / `scenes/map/slice.tscn`，纯地图场景保持原行为。

- 步行 4.5 → 5.175 m/s，冲刺 8 → 9.2 m/s，均提高 15%；脱水速度 2.5 m/s、体力与水分规则保留。
- 便利店与诊所室内保留远侧墙，近侧改为 0.9 m 高墙段，门洞保持空隙。新增边界只负责显示，原墙体碰撞不变。
- 三扇可操作门使用独立可见门扇，开门旋转 90°，门框和门槛持续显示；原位置的碰撞按开关状态启停。
- 交互目标改为可达范围内最近对象；满背包时不再累积无效搜刮进度，并显示腾空提示；诊所十字标志随原外墙隐藏，避免悬空。
- 试玩标题使用《余生》。实现与自动验收均在 `scripts/slice.gd`。

图形验收：Godot 启动 `res://scenes/map/slice.tscn -- --polish-test`，测量生产移动循环中的步行/冲刺速度，逐一实际穿越三扇门，检查两栋建筑四面边界及门扇显示，测试满包提示，然后沿完整路径走到诊所、按住 E 搜药、走回收银台并交付。测试运行会自动退出。证据见 `verification-polish.log` 与 screenshots/08、09、10 三张截图。

## 试玩相机与地图重构基础

仅试玩场景启用新相机：**按住右键左右拖动**可连续水平旋转，松开后保持角度；**滚轮**平滑缩放；**Home**平滑恢复默认 45° 方位、43° 俯角及 43 m 正交视野。视野范围为 18–200 m，覆盖室内与街区。WASD 相对当前已显示的镜头方向移动，W 朝屏幕上方。纯地图观察场景继续保留原操作。

遮挡检测以五条覆盖玩家身体的正交视线工作，命中的单独墙面、屋顶或较大道具在约 0.2 秒内降至 22% 不透明度，离开视线后短暂防抖并恢复。只替换命中表面的独立材质副本；结束后恢复原材质资源及阴影设置。门扇、搜刮物与行走碰撞不参与透明处理。室内屋顶隐藏与近侧矮墙剖切保留，旋转到另一侧时再按实际遮挡淡化远侧高墙。

新实现：`scripts/exploration_camera.gd`、`scripts/occlusion_fader.gd`；`scripts/slice.gd` 接入两组件。验收入口：启动试玩场景并带 `-- --camera-test`，执行 `scripts/camera_verification.gd`。日志保存为 `verification-camera.log`；`screenshots/camera/` 包含两圈旋转的 16 张连续采样、近远缩放和三处遮挡截图，`sequence.json` 记录真实相机角度与淡化数量。连续截图是自动输入驱动的实机证据，不是手动游玩视频。

下一轮地图提案见 `docs/中国街区重构方案.md`。当前地图仍是旧占位街区，尚未实现提案里的 10 栋可进入建筑。

限制：当前用 Mesh 包围盒作为遮挡检测体，适合现有基础几何；未来 GLB 复杂模型应提供精简检测体并显式登记。一个完整屋顶 Mesh 被命中时会整片淡化，不能局部挖洞；正式资产需按屋面/墙段拆分。多层透明表面的排序仍受 Compatibility 渲染器限制。门保持可辨，因此紧贴关闭门扇时仍可能被门局部遮住。此轮没有实现全部建筑可进入或多楼层行走。
