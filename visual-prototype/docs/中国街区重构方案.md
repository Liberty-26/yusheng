# 《余生》第一张中国城市街区：下轮实施设计稿

状态：设计提案，尚未建图。本轮只实现相机与遮挡基础。以下尺寸是原型构图建议，不是道路或消防规范；正式资产阶段再核查比例与实际标准。空间逻辑已参考用户提供的上海静安大悦城附近卫星图和白膜地图（参考背景由“游戏大脑”同步），吸收其道路层级、河道与桥梁、混合街区及建筑密度之间的关系；不复刻上海，首图选择中国二三线城市的中等密度。

## 目标与边界

建议从当前 180 × 180 m 占位地图改为约 **240 × 220 m** 的单个混合街区。只建 10 栋有入口、可到达室内的实际建筑，不添加不可进入的背景楼。中等密度、老住宅小区与沿街商住混合；大形体、低饱和半写实风格化，不照搬上海中心城区的密集天际线。

“每栋可进入”表示至少有一条可完成的合法进入路径与一个实际室内空间，不表示所有楼层都制作。中高层也有真实首层入口、门厅与楼梯；未开放楼层以可见状态说明，不能用漂亮外壳冒充整栋可探索。

主干道在地图南缘，不从小区中央贯穿。次干道在北缘，东侧支路连接两者，店后巷与小区内部道路形成步行回路。小区有清晰围墙、院门与两处出入口；不要把围墙随机拼成迷宫。主入口对接人行道，住宅单元门朝小区内部，商铺朝街，后勤朝后巷。

主干道横断面原型可先分成车行空间约 14 m、两侧非机动车空间各 2.5 m、两侧人行空间各 3 m，另留绿化/设施带。次干道收窄为双向车行与慢行空间；支路更窄，后巷仅承担步行及卸货组织。重要的是层级和连续性，不是第一版铺设全部车道细节。

## 中国道路与公共空间元素

- 人行道保持连续，路口设缘石坡道与斑马线；车行道设停止线、车道线，方向标线集中在路口。
- 非机动车道用低饱和铺装或标线区分，公交站、路口与店门前留出连续通行位置；不拿随处散放自行车代替慢行体系。
- 主干道设置少量机非隔离护栏，路口与过街处断开。禁止护栏封死行人过街路线。
- 公交站只放在主干道直线路段，候车空间退在人行道侧，避免堵门与占住路口。
- 小区内沿边划停车位，消防/服务通道连续连到两个院门；消防通道、楼门口与转弯处不作为废车装饰点。
- 行道树形成街道节奏，小区绿化围绕院落；低矮绿篱不能切断门口可达性。
- 路灯、配电箱、垃圾分类点、快递周转架少量集中，采用中文招牌、卷帘门、空调外机、雨棚与普通瓷砖/涂料立面建立地域识别。
- 末日痕迹来自局部破损招牌、封窗、停摆设施和一两段可绕行障碍。不得随机堆满每条路；保留玩家可读的主次路径。

## 首批室内模板

**居民楼模板：**单元门 → 小门厅 → 楼梯平台 → 户门 → 客厅/餐厅 → 厨房、卫生间、卧室。首批复用一室与两室两套模板，用家具朝向和门窗变化区分。楼梯与平台保留真实洞口；二楼玩法单独验收后开放，不能直接沿用现在的视觉剖切当作可走楼层。

**便利店模板：**正门、双通道营业区、收银台、可通行的货架间距、后储藏、卸货门。入口留有停步、开门、转身空间，门扇不穿柜台。保持已有取药归还点语义，搬迁后同步更新路线验收。

**社区诊所模板：**入口/接待 → 走廊 → 诊室、药房、卫生间；后勤门通后院。药柜不是正门旁一只孤立箱子，应落在药房里，同时保持起步阶段易辨路。当前方案用社区卫生服务站，不在首图塞完整综合医院。

**小高层首层模板：**门斗、门厅、值班室、楼梯、电梯厅占位。电梯无功能，不新增电梯系统；上部楼层以封闭梯段和说明限制。所有外部入口必须与内部位置对应。

## 门状态与替代入口规则（下轮设计，非本轮功能）

| 状态 | 视觉与提示 | 通行约束 | 另一条路径 |
|---|---|---|---|
| 正常 | 门扇、门框完整；提示开/关 | 关门碰撞，开门通行 | 第二入口可保留正常或非必需 |
| 上锁 | 明确锁具/链条；提示“上锁” | 不把普通 E 开门当成解锁 | 初期使用已开放后门；钥匙机制未做前不放唯一锁死入口 |
| 堵塞 | 门后/门前可辨的实体障碍；提示“被堵住” | 障碍碰撞稳定 | 侧门或后巷入口；不要求未实现的搬物能力 |
| 损坏 | 斜挂或缺失门扇；提示“损坏，无法关闭” | 洞口可通行，残片不制造隐形堵点 | 不强制额外入口，必要时仍保留疏散门 |

每栋建筑必须通过“出生点 → 可达入口 → 实际房间 → 离开”的路径验收。不得让全部入口同时处于不可解状态。门洞、替代入口、窗台若需要攀爬，必须等能力实现后才能计入可达路径。当前小高层开放首层即可满足“建筑可进入”，不把未实现的上层作为替代路线。

## 模块化资源与数据组织

| 模块 | 第一轮 Godot 几何占位 | 后续 Blender → GLB |
|---|---|---|
| 道路直段、路口、人行道、坡道、标线 | 分段 Mesh 与平面贴花 | 缘石转角、破损地面等少量特形模块 |
| Wall_2m / 4m、门洞、窗洞、转角、楼板、楼梯平台 | 统一米制模数、独立可替换节点 | 正式墙窗门、楼梯、屋顶、阳台模块 |
| 居民楼入口、沿街门头、卷帘门 | 清楚形状和招牌色块 | 外机、栏杆、雨棚、卷帘、瓷砖立面等识别模块 |
| 公交站、护栏、路灯、垃圾点、自行车停车设施 | 限量基础几何 | 共享低中模道具与简化碰撞 |
| 货架、收银、诊室、厨卫家具 | 优先留足通道与门扇净空 | 正式共享室内 Kit，减少商品小件噪声 |

建筑根保留 building_id，楼层 floor_id，房间 room_id，入口单独 entry_id 与状态。几何、行走碰撞、门的交互锚点、遮挡检测分开。后续不要再靠模型名称推导所有碰撞；GLB 替换时保留语义父节点，显式登记可淡化表面和入口。

本轮遮挡方案按单个墙段/屋顶 Mesh 淡化，因此正式资产也应分段；禁止把一整栋连外墙、屋顶、室内打成一个 Mesh。大型屋面必要时按体量拆段，透明只动被射线命中的几何。材质高粗糙度，颜色延续冷灰蓝、灰绿与少量褪色功能色。

## 下轮最小实施顺序与验收门槛

1. 先画道路与 10 栋 footprint、入口和楼内可行走区域；用可达性检查确认没有死入口，再替换当前布局。
2. 先迁移便利店—诊所闭环，验收实际往返、门状态、相机八方向、遮挡恢复；随后复用首层模板填其余 8 栋。
3. 给各栋建立首层入口到室内路径验收。位置数据集中记录，避免交付点/搜刮点散落为脚本坐标。
4. 用户认可街区构图与室内比例后，再制定 Blender Kit 尺寸与出图规范。不在本轮启动精模或整城开发。

本稿不批准新增 NPC、战斗、建造、钥匙系统、攀爬、电梯、二层玩法或存档；这些能力需要另行派发。
